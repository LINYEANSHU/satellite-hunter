# 已知问题与后续计划

更新日期：2026-10-31（Phase 4 完成时）

## 已知限制（如实声明）

1. **SatDump 真实解码未实测**：开发环境 WSL sudo 需要密码，无法静默安装。
   适配层已用 mock 可执行文件完成全流程测试；安装后即可用（docs/satdump.md）。
   —— 需求 Phase 3 验收要求"若样本无法成功解码，必须准确报告问题"，此处如实报告
   环境限制，未伪造硬件/真实解码结果。
2. **模拟接收为简化模型**（SIMULATED_RF）：自由空间路径损耗 + 大气经验插值 +
   确定性指向模型。不含电离层闪烁、雨衰、极化失配细节；发射参数对无公开资料
   卫星使用标注的游戏假设。
3. **TLE 兼容**：>5 位目录号的 TLE（扩展格式）解析为尽力兼容；OMM 为主格式不受影响。
4. **WSL SatDump 路径**：适配器可探测 WSL 内的 satdump，但录波路径需经
   `/mnt/...` 转换，当前版本建议使用 Windows 原生 satdump.exe。
5. **浏览器性能**：'全部活跃'分组（~2 万星）一次仅渲染前 2000 颗；建议按分组筛选。
6. **单一信号链**：每站每类设备一件（槽位制）；多天线阵列、双极化等在后续版本。
7. **WebSocket**：已建立 hub 基础设施，当前 UI 用轮询（一致性与简化优先）。
8. **R3F 初始测量竞态**：StrictMode 下画布偶发 300×150，已用挂载后补发 resize 兜底。
9. **de421.bsp（17MB）**：仅测试用（Skyfield 交叉验证），首次运行联网下载，已 gitignore。
