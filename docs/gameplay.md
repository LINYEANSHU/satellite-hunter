# 玩法说明

## 你是谁

一名地面卫星观测站运营者。从一座基础地面站、一根鞭状天线和一台入门 SDR 开始，
最终建成自动化运行的全球接收网络。

## 核心循环

```
探索 3D 地球发现卫星 → 预测过境 → 检查/升级设备 → 规划接收任务
   → 执行（跟踪/接收）→ 获得数据与奖励 → 解锁图鉴/成就/研究 → 扩建网络
```

所有环节有真实逻辑约束：设备频段不覆盖则任务无法创建；卫星不在视野内不能规划；
站内有故障设备不能启动任务；同一时刻任务数受计算机并发限制。

## 三种模式

| 模式 | 状态 | 说明 |
|---|---|---|
| A 探索与经营 | ✅ 当前 | 真实轨道 + 简化 RF 模拟（SIMULATED_RF），可时间加速 |
| B 真实数据挑战 | ✅ 录波解码 | 导入 IQ 录波 → SatDump 离线解码（RECORDED_IQ / DECODED_OUTPUT） |
| C 真实地面站 | 预留 Phase 5 | 实时 SDR 接收（LIVE_SDR），接口已预留 |

## 起步流程（10 分钟上手）

1. **主菜单**创建存档进入。
2. **轨道探索**页：右侧「选址建站」→ 点击地球任意位置 → 命名建站（首站免费）。
   站点自动获得初始设备套件（鞭状天线/入门SDR/无转台/单任务计算机/2GB存储）。
3. 点击列表中的 ISS (ZARYA)：右侧面板显示实时位置、轨道根数与该站未来 48h 过境。
4. 点「建立接收任务」→ 到**任务控制**页 → 任务到达 AOS 前点「启动」。
5. 用底部时间控制切 **1000×** 快进——过境开始后监视面板实时显示方位/仰角/
   多普勒/SNR/数据缓存；越过 LOS 自动结算。
6. 奖励到账 → **设备管理**页采购升级（八木天线+转台是质变）→ 重复。

## 系统

- **经济**：Credits（购买/建站/维修）、研究点 RP（研究解锁）、XP（等级）。
  任务奖励按数据完成度缩放——低仰角短弧、指向不良都会真实减产。
- **设备**（7 类，参数分真实 RF 参考值与游戏数值两层）：
  天线（增益/波束/指向需求）、SDR（频率范围/带宽/噪声）、低噪放、滤波器、
  转台（跟踪速度/精度）、计算机（并发）、存储（容量上限，可清空）。
- **简化 RF 模型**：FSPL + 大气衰减(仰角插值) + 指向损失(转台精度/跟踪超速)
  + 系统噪声 → SNR → 质量 0-100 → 数据率。多普勒由真实距离变化率计算。
- **图鉴**：tracked → received → decoded 三档；收藏、首次观测时间、成功次数。
- **成就**：32 项，全部由游戏事件驱动判定（First Contact / Night Watch /
  Signal Hunter / Orbital Collector / Ground Station Engineer / Mission Controller 等）。
- **研究**：RP 解锁被动加成（SNR/数据/奖励/故障率/调度上限），有前置链。
- **自动调度**：确定性规则（频段覆盖→冲突→仰角/收藏/奖励加权评分），
  一键把未来 24-72h 的最优过境打包成任务。
- **特殊事件**：每日确定性判定（种子=存档+站+日期），设备故障（需维修）/
  奖励窗口。全部标注 GAME_EVENT 虚拟，绝不伪造现实卫星事件。
- **时间**：现实/暂停/1×-1000×/自定义跳转。快进明确属于游戏仿真时间，
  过境预测随之变化；历史精度受根数年龄约束（UI 警告）。

## 信号实验室

导入 IQ 录波（cu8/cs8/cs16/cu16/cf32）→ 频谱/瀑布/IQ波形/星座图（后端分块
FFT）→ 回放拖动逐段检查 → 安装 SatDump 后一键离线解码 → 输出收藏进图鉴
（DECODED_OUTPUT）。安装指引见 docs/satdump.md。

## 常见问题

- **为什么我的任务失败/数据很少？** 检查链路余量：低仰角、无转台用定向天线、
  SDR 噪声高、存储满、站内设备故障都会真实影响。
- **为什么看不到某些卫星的任务？** 目录中"可轨道追踪"≠"有公开可接收下行"；
  无可靠参数的卫星使用明确标注的游戏假设默认值。
